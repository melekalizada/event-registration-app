# Event Registration App

A simple web application that allows users to register for a technology event.

## GitHub Repository

https://github.com/melekalizada/event-registration-app

## Features

- Registration form with validation
- Participant list with delete option
- Statistics: total participants, average age, most popular technology

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Fill in the form with your full name, email, age and technology.
2. Accept the terms and click Register.
3. Your name will appear in the participant list below.
4. You can delete participants or view statistics.
